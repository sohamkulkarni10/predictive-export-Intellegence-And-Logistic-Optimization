# India Agricultural Export — Tariff & Procedure Guide

## Export documentation basics
Indian exporters of agricultural commodities typically need:
- Import Export Code (IEC) from DGFT
- GST registration
- Commodity Board / APEDA registration where applicable (many agri products)
- Shipping Bill filed on ICEGATE
- Commercial Invoice, Packing List, Bill of Lading / Sea Waybill
- Certificate of Origin (preferential if FTA applies)
- Phytosanitary Certificate (for plants/plant products) from Plant Quarantine
- Fumigation certificate when required by destination

## Tariffs overview
- India generally does **not charge export duty** on most processed agri items, but specific commodities can face temporary export restrictions, MEP (minimum export price), or duties.
- Destination **import duty / customs tariff** is charged by the importing country on CIF or customs value.
- Preferential tariffs may apply under FTAs (e.g., India-UAE CEPA, India-Australia ECTA, ASEAN-related arrangements depending on origin rules).
- Always verify the latest HS code duty using the destination customs tariff schedule.

## Common HS code families (indicative)
- Wheat: 1001
- Maize/Corn: 1005
- Soybean: 1201
- Sugar: 1701
- Coffee: 0901
- Cotton (not carded/combed): 5201
- Onions: 0703
- Turmeric: 0910

## Port choice tips
- West coast ports (Mundra, JNPT, Kandla, Hazira, Cochin) often suit Middle East / Europe lanes.
- East coast ports (Chennai, Visakhapatnam, Paradip, Kolkata/Haldia) often suit Bangladesh, SE Asia, East Asia.
- Inland haulage to the wrong coast can erase ocean freight savings.

## Container & logistics notes
- 20FT is common for denser agri cargo; payload limits matter more than volume for grains/sugar.
- THC, documentation, customs processing, and container extras add to door-to-port cost.
- Transit time risk should be weighed against freight when demand is urgent (festival / shortage windows).

## Compliance risks
- Export bans / quota / licensing can change quickly for onion, wheat, sugar, etc.
- Destination SPS (sanitary/phytosanitary) rejection risk is high without proper certificates.
- Under-invoicing and misclassification of HS codes create customs penalties.
